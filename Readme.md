# Laundry Services Web Application

A responsive single-page web application for booking laundry and dry cleaning services.

## Features
- **Responsive Navigation Bar**: Contains brand logo, quick navigation links, and user indicator.
- **Hero Section**: Includes a CTA button with smooth auto-scroll to the booking section.
- **Achievements Overview**: Displays metrics and operational experience.
- **Dynamic Booking System**:
  - Live service catalog with dynamic "Add Item" / "Remove Item" state toggles.
  - Interactive summary table updating items and total amount in real time.
  - Booking form connected to **EmailJS** to send booking receipts directly to email.
- **Quality USPs & Newsletter**: Highlights key value propositions and provides a subscription interface.
- **Footer**: Includes quick links and social media channels.

## Setup & EmailJS Configuration
1. Open `script.js`.
2. Replace `'YOUR_PUBLIC_KEY'`, `'YOUR_SERVICE_ID'`, and `'YOUR_TEMPLATE_ID'` with your credentials from [EmailJS](https://www.emailjs.com/).
3. Open `index.html` in any browser or launch with Live Server.
